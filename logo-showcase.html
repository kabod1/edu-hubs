Design Elements

  • Shopping cart symbolizes e-commerce
  • Network nodes represent marketplace connections
  • Modern gradient colors
  • Clean, professional typography
  • Scalable SVG format

Usage Guidelines

  • Maintain minimum size of 40px height
  • Use on light or dark backgrounds
  • Don't modify colors or proportions
  • Ensure adequate white space around logo
  • Use appropriate version for context

File Formats

  • logo.svg - Primary logo with text
  • logo-icon.svg - Icon only version
  • logo-horizontal.svg - Horizontal layout
  • All files are vector-based (SVG)
  • Infinitely scalable without quality loss
